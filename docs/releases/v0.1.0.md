# Pair.nvim v0.1.0 — Alpha

The first public alpha of Pair: code with an AI agent while staying hands-on in Neovim.

## What you can do

- Chat, Ask about selected code, Change a selection, and Insert at the cursor in one shared agent conversation.
- Review proposed code in your unsaved buffer; accept, reject, inspect a full diff, or save to accept.
- Send the visible buffer, including unsaved edits, as context by default.
- Read streamed answers in chat and beside your code, with native Vim input and proposal controls.
- Cancel requests, start fresh chats, resume saved conversations, and switch backends and models.
- Keep your last backend and model selections across Neovim restarts.

## Backend coverage

Live macOS workflows passed with **Codex**, **Antigravity CLI**, **GitHub Copilot CLI**, and **OpenCode** using an OpenRouter key and `openrouter/openai/gpt-4.1-mini`.

**Claude Code ACP**, **legacy Gemini CLI ACP**, and direct **OpenAI, Anthropic, and Gemini APIs** are experimental. Their mock/loopback checks pass; authenticated live workflows still need testing. Other accounts and models are unverified. CLI backends use their existing login; direct APIs use separately billed API keys.

See [backend setup](https://github.com/sampsn/pair.nvim/blob/v0.1.0/docs/backends.md) and [tested versions and results](https://github.com/sampsn/pair.nvim/blob/v0.1.0/TRANSPORT.md).

## Install

Requires Neovim **0.11+** and a signed-in agent CLI, or `curl` and a provider API key. With lazy.nvim:

```lua
{
  "sampsn/pair.nvim",
  tag = "v0.1.0",
  config = function()
    require("pair").setup()
  end,
}
```

Codex is the default backend. Sign in with `codex login`, open a project, and use `:PairChat`. Run `:checkhealth pair` for setup checks or `:help pair` for the full guide.

## Alpha limits

- One active workspace and one pending proposal per Neovim instance. Editing the target while a proposal is generating invalidates it.
- Prompts use the visible buffer; agent commands use saved files on disk.
- Antigravity can run commands in Pair's filesystem sandbox on macOS and Linux. Explicit writable output folders can receive generated files without proposal review. Codex uses its native read-only sandbox; ACP presets and direct APIs have inspection-only tools.
- Your prompt and attached code go to the selected provider. Pair keeps local conversation history under `stdpath('state')/pair`.
- Direct API history is limited to 2 MiB or 400 messages; provider context limits may arrive sooner.
- Linux CI checks local protocols and editor behavior; live backend validation was performed on macOS.
