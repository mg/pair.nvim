# Pair.nvim v0.1.1 — Alpha

## Fixed

The Pair Ask input now opens below the last selected line. Forward and backward selections, character selections, and explicit line ranges use the bottom of the selection as the anchor. The source cursor stays in place.

## Update

If your lazy.nvim spec pins a release, change it to `tag = "v0.1.1"` and update the plugin. Restart Neovim to load the change.

This remains an alpha prerelease. Backend coverage and other limits are described in the [v0.1.0 notes](https://github.com/sampsn/pair.nvim/releases/tag/v0.1.0).
